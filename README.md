# 🗺️ 小满的地图 · 故事生产间

为 6-13 岁中国家庭女孩创作的睡前故事播客生产工具。单文件网页,无需安装。

**在线使用**:https://hwhovo77.github.io/girls-cosmos/

## 三个 AI 小助手

- **✨ 策划** —— 根据主角、故事味道、地点,想一句核心事件
- **✍️ 写手** —— 按《故事圣经》(世界观/三主角/八条铁律/TTS 规则)写 1400-2400 字单集故事
- **🔎 审校** —— 只挑毛病不动笔,输出"过/不过 + 原句证据"

以及四个确定性组件:排班小管家(节奏约束)、自动体检(红线词/品牌/句长/数字)、故事库记忆(跨集去重)、状态流转(写作中 → 写好了 → 已通过 → 配音中 → 可以听啦)。

## 使用

1. 打开网页,进「设置」填 AI 钥匙(Anthropic 或 OpenAI 兼容接口,密钥只存本浏览器)
2. 「创意工坊」选主角、挑故事味道、定地点 → 开始写故事
3. 体检有问题可一键让写手改;「看过了,通过」后去「故事库」生成配音
4. 「小电台」试听,支持倍速、快进快退、自动连播

配音需 OpenAI 兼容的语音接口(设置里单独配置);不配也能用浏览器自带朗读试听。
